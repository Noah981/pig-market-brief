1. 처리 목적과 기본 원칙
돈돈해는 양돈 관련 시황·질병·날씨·지원사업 정보와 일정 관리 기능을 제공합니다. 회원가입이나 로그인을 요구하지 않습니다. 운영자는 별도의 사용자 계정 데이터베이스를 운영하지 않으며, 광고 및 광고 목적의 추적 SDK를 사용하지 않습니다.

2. 기기에 저장하는 정보
선택한 지역, 사용자가 설정한 농장 위치와 좌표, 알림 설정, 할 일과 반복 일정 등은 기능 제공을 위해 기기에 저장됩니다. 운영자의 별도 서버로 일정이나 농장 설정을 업로드하지 않습니다. 기기 데이터는 이용자가 앱 데이터를 삭제하면 제거됩니다. 기기 운영체제의 백업·복원 기능은 이용자의 기기 설정과 해당 서비스 정책에 따릅니다.

3. 위치정보
이용자가 위치 기능을 사용하고 권한을 허용하면 현재 위치를 확인하여 행정지역 표시, 주변 질병 거리 계산, 날씨 조회에 사용합니다. 위치를 지속 추적하거나 운영자 서버에 이동 경로를 저장하지 않습니다. 주소 변환에는 Android 기기의 위치·주소 변환 서비스가 사용되며, 좌표 또는 주소가 해당 서비스 제공자에게 전달될 수 있습니다. 기상청 조회에는 좌표를 변환한 예보 격자를 전송합니다. 이용자는 위치 권한을 철회하거나 지역을 직접 선택할 수 있습니다. 권한을 철회해도 이미 기기에 저장된 농장 위치는 별도로 변경 또는 삭제해야 합니다.

4. 푸시 알림과 외부 서비스
앱 종료 상태의 알림 제공에는 Google LLC의 Firebase Cloud Messaging(FCM)을 사용합니다. Firebase 설치 식별자, 푸시 등록 토큰, 알림 주제 구독 정보가 알림 전달을 위해 처리됩니다. Google은 서비스 운영 과정에서 IP 주소 등 기술 정보를 처리할 수 있습니다. 운영자는 별도 서버에 사용자 기기 토큰 또는 사용자 위치를 저장하지 않으며, 공개 돈가와 선택한 질병 주제에 따라 알림을 발송합니다. Android 알림 권한을 끄면 알림 표시가 중지되지만 Firebase 식별자가 즉시 삭제되는 것은 아닙니다.
Google은 Firebase 정보를 해외를 포함한 글로벌 인프라에서 처리할 수 있습니다. Google 공식 설명에 따르면 FCM 설치 식별자는 설치 ID 삭제 API 요청 전까지 유지되며, 삭제 요청 후 운영 및 백업 시스템에서 제거하는 데 최대 180일이 걸릴 수 있습니다. 앱 삭제 또는 기기 데이터 삭제가 Google의 서버 정보 즉시 삭제를 보장하지는 않습니다.

5. 공식 데이터 조회 및 외부 링크
앱은 공식기관 및 공개 데이터 배포 경로에 인터넷으로 접속합니다. 접속한 서비스에는 요청에 필요한 예보 격자, 조회 조건, IP 주소 등 통신 정보가 전달될 수 있습니다. 외부 공고나 원문 링크를 열면 해당 사이트의 개인정보처리방침이 적용됩니다. 사용자 농장 위치나 일정을 공개 데이터 저장소에 게시하지 않습니다.
