# 오늘돈가 4.0 — 발명 설명서 초안

## 발명의 명칭
다중 외부환경·시장·가축질병 및 농장상태 데이터를 이용한 양돈농장 위험 우선순위 산출, 단계별 현장조치 생성 및 결과 피드백 방법과 시스템

## 기술적 과제
기존 양돈 앱은 가격·기상·센서·환기·질병 정보를 각각 표시하거나 특정 설비를 제어하는 데 집중한다. 본 발명은 서로 다른 시간축과 신뢰도를 가진 공공정보와 농장 현장정보를 하나의 사건 단위로 정규화하고, 돈군/성장단계별 위험을 산출한 뒤, 사용자가 실제로 수행할 수 있는 점검 순서를 생성하고, 수행 결과를 다음 위험평가에 재반영하는 폐루프 의사결정 지원을 목표로 한다.

## 핵심 구성
1. 데이터 수집 계층: 돈가, 기상/특보, 법정가축전염병, 공개 질병정보, 농장 기록, 생산성 지표.
2. 신뢰도 계층: 공식확정 / 공개정보-확인중 / 사용자관찰을 분리하고 동일 사건을 중복 제거·승격.
3. 상황 벡터: 지역, 날짜/계절, 돈군단계, 일교차, 온습도, 질병근접도, 생산성 이상, 시장변동을 정규화.
4. 위험 엔진: 환경·질병·생산·출하·시장 위험을 각각 산출하고 근거를 보존.
5. 행동 엔진: 위험별로 '관찰 → 측정 → 환경/관리 조치 → 감별검사 → 전문가 연결'의 순서를 생성.
6. 우선순위 엔진: 심각도×신뢰도×근접도×시간민감도×돈군취약도를 이용해 오늘의 TOP3를 생성.
7. 피드백 엔진: 사용자의 점검결과와 후속 생산성 변화를 저장해 동일 농장의 다음 우선순위에 반영.
8. 설명가능성: 모든 권고에 데이터 출처, 발생시각, 적용지역, 추천 이유를 연결.

## 독립항 후보 개념
복수의 이질적 데이터 소스로부터 양돈농장 관련 데이터를 수집하는 단계; 데이터별 출처 신뢰도와 시간 유효성을 산출하는 단계; 대상 농장의 위치 및 돈군단계에 따라 상황 벡터를 생성하는 단계; 복수 위험범주의 위험값을 계산하는 단계; 위험값과 신뢰도 및 시간민감도를 이용하여 점검행동의 우선순위를 산출하는 단계; 각 우선순위에 대해 관찰·측정·조치·전문가연결 중 적어도 둘 이상을 포함하는 단계형 행동경로를 생성하는 단계; 사용자의 수행결과를 수신하여 후속 위험평가 가중치를 갱신하는 단계를 포함하는 양돈농장 의사결정 지원 방법.

## 종속항 후보
- 공식 확정정보와 공개 미확인정보의 상태 전이 및 중복사건 병합.
- 기상 일교차와 돈군단계를 결합한 환기/보온 점검 우선순위.
- 질병 의심 시 환경원인 배제 후 감별검사 및 수의사 연결을 생성.
- 경락가격의 전일·전월·전년 변동과 출하예정정보를 결합한 출하점검 우선순위.
- 저탄소/무항생제 등 농장별 가산 지급률을 적용한 예상정산.
- 권고 수행 전후 FCR·폐사율·출하일령·출하체중을 비교해 권고효과를 추적.

## 선행기술 회피 방향
돈사 환기 자동제어 자체, 단순 온습도/가스 임계치 알람 자체, 단순 질병 ML 예측 자체를 권리 핵심으로 삼지 않는다. 핵심은 이질적 외부 공공데이터+농장상태+신뢰도/시간유효성+행동 우선순위+단계형 조치+결과 피드백의 결합이다.
