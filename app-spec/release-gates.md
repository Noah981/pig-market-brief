# 출시 게이트 — TodayPig 4.0

출시 후보는 아래를 모두 통과해야 한다.

- [ ] KAPE 전국(제주 제외) 대표 돈가를 공식 화면과 동일 날짜에 대조 검증
- [ ] 가격 0/누락을 실제값으로 오인시키지 않음
- [ ] 3개년 월별 데이터 36개월 이상 확보 및 월보 표본 대조
- [ ] 공식 질병/공개확인중/농장관찰 상태가 UI에서 구분됨
- [ ] 오늘 TOP3가 이유→확인→조치→전문가 연결을 제공
- [ ] 지역 선택 저장 및 위젯에도 동일 지역 적용
- [ ] 정산계산 인증 가산은 사용자 계약값임을 명시
- [ ] 오프라인에서 마지막 확정 데이터와 시각 표시
- [ ] 접근성/큰 글씨/다크모드 기본 QA
- [ ] 개인정보 최소수집·동의·삭제 경로
- [ ] 릴리스 서명 APK/AAB
- [ ] 크래시 없는 실기기 스모크 테스트
- [ ] 특허 출원전 공개 범위 검토

## 데이터 검증 표본
KAPE 국가승인통계 월보의 월 평균 경락가격을 자동 테스트의 기준점으로 사용한다. 월보는 도체별 kg당 평균 경락가격을 매월 공표한다.
