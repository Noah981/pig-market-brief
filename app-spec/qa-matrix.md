# TodayPig 4.0 QA matrix

## 데이터
| ID | 조건 | 기대결과 |
|---|---|---|
| D01 | 가격 API 실패 | 마지막 확정값/시각 유지, 0원 금지 |
| D02 | 전년 데이터 없음 | 집계중 표시 |
| D03 | 등급 데이터 없음 | 등급가격 없음 명시 |
| D04 | 제주 데이터 | 전국 대표가격과 혼합 금지 |
| D05 | 공개 질병속보 | 공식확정과 다른 배지 |
| D06 | 공식 발생 확인 | 기존 공개사건과 병합·승격 |

## 현장 판단
| ID | 조건 | 기대결과 |
|---|---|---|
| F01 | 일교차 >=10℃ | 최소환기/외풍/돈군행동 우선 |
| F02 | 일교차+기침 | 환경확인 후 수의사 감별 단계 |
| F03 | 설사+폐사증가 | 고위험, 일령/탈수/확산 확인 |
| F04 | 인근 공식 질병 | 방역이 다른 위험보다 우선 |
| F05 | 섭취저하 | 음수→급이→환경/질병 순서 |

## UX
- 홈 첫 화면에서 가격/기준일/TOP3가 스크롤 전 또는 첫 스크롤 내 노출
- 상승/하락은 색만으로 구분하지 않고 ▲▼와 숫자를 병기
- 데이터 시각과 출처 노출
- 경고는 공포 표현 대신 행동을 명확히 표시
- 모든 사용자가 인증 가산율을 계약값으로 직접 입력
